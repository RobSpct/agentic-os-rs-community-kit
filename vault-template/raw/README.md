# raw/ — Quellen-Archiv

Unveränderte Quellen: Artikel, Doku-Auszüge, Recherche-Rohtexte, Gesprächsmitschriften.

**Immutable.** Einmal abgelegt: nie ändern, nie löschen. Wenn sich etwas als falsch
herausstellt, korrigiert das die Wiki-Seite — nicht die Quelle.

Dateiname: `<thema>-<YYYY-MM-DD>.md`

Wozu: Eine Wiki-Seite behauptet etwas, `raw/` belegt es. Das `sources`-Feld im Frontmatter der
Wiki-Seite zeigt hierher.
